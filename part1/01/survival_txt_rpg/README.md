# Survival | Text RPG

> No modules.  
> No data structures.  
> No arrays.  
> No objects.  
> Just variables. Just spaghetti. Just hardcore.

## About

This project was created as a learning exercise to build a complete text-based RPG using only the most basic JavaScript features.

The goal was not to write perfect code.

The goal was to understand how programs work internally when you do not have convenient tools to hide the complexity.

As a result, the entire game is built with:

- Variables
- Constants
- Functions
- Conditions
- Loops
- Pure determination and questionable life choices

## Features

- Character creation
- Multiple locations
- Shop system
- Inventory management
- Hunting system
- Mining system
- Health management
- Experience and leveling

## Technical Challenge

Modern developers often solve problems using:

- Arrays
- Objects
- Classes
- Modules
- Frameworks
- Libraries

This project intentionally avoids all of that.

Every item, every resource, and every game mechanic is managed manually through separate variables.

It is inefficient.

It is painful.

It is educational.

## Developer Notes

- Why data structures exist
- Why modules exist
- Why developers separate code into files
- Why game engines exist
